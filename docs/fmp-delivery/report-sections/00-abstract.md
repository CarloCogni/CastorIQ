# Abstract

CastorIQ is a locally deployable, bi-directional LLM assistant that closes the "Split Reality" gap between IFC building models and the unstructured technical documents that govern them. Where existing tools either check models against rule sets or parse documents read-only, CastorIQ links both domains in a shared 1024-dimensional vector substrate and, as its core contribution, writes changes back to the IFC file under maximal verification: the model writes the change as IfcOpenShell code, the code runs once on a copy, the measured diff is gated deterministically and explained by a second model that never sees the request, and a human approves the measured result. A Retrieval-Augmented Verification (RAV) layer checks every proposal against the project documents, and every approved change is a Git commit. Seven operational surfaces share one substrate: Ask, Modify, Conflicts, History, Explore, Schedule (4D and 5D) and 7D Facilities. On 8 GB of graphics memory a 7B local model passed 41 of 95 write-back benchmark prompts, and 46 of 46 written files changed nothing outside the selection; a cloud model passed 65 of 95. A retrieval fix raised the F1 of the document conflict scanner from 0.24 to 0.74. Over four public models, Ask answered 20 of 22 questions with one right answer and 11 of 14 narrative ones. Everything runs without cloud dependency, under AGPL-3.0.
