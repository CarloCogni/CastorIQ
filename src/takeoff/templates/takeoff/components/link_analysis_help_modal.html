How 4D Link Analysis works

What is it?

4D Link Analysis is a read-only workspace for schedule task ↔ model element links. It focuses on 4D linking coverage, attention signals, and Time View readiness. Model quantity readiness belongs under Quantities as a separate surface — not on this screen.

Lifecycle

After IFC indexing and link apply under Links, this page reads applied/confirmed bindings and the IFC index. Reload the page to see updated aggregates — this screen does not apply, approve, or remove links.

How to use it

  • Schedule Link Coverage — how much of the schedule connects to model elements.
  • Model Link Coverage — how much of the model is used in current 4D links.
  • Actionable Link Review — Pending review / Broad / Partial only (not unlinked/non-model).
  • Time View Readiness — linked tasks that have schedule dates for playback review.
  • Review Task / Element / Grouped rows; expand a task for linked element previews.
  • Open Links or Time View for editing or playback — not from destructive actions here.

Attention / Actionable Link Review

Attention is derived from link-analysis counts only. Actionable Link Review counts tasks that need follow-up (excludes Unlinked/non-model):

  • Pending review: 0 confirmed links and pending review links exist
  • Broad link: confirmed linked elements ≥ 100
  • Partial: confirmed links exist and pending review links also exist

Unlinked/non-model tasks are shown for context in Schedule Coverage and Task Review Breakdown, but are excluded from Actionable Link Review. This is not an issue tracker risk model, schedule criticality, or QA/QC status — only a task-model link attention signal.

Who can do what

BIM coordinators and planners use this page read-only. Link apply/remove stays on Links with confirmation. Playback stays on Time View.

Caveats

  • Schedule link coverage and model link coverage use different denominators.
  • Only applied/confirmed links (needs_review=False) count as linked.
  • Time View readiness requires confirmed links plus both start and finish dates.
  • This screen is 4D link analysis only — not a takeoff workspace.
