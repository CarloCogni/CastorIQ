How Quantities Works

What is it?

Quantities builds a deterministic Quantity Preparation Data Model from indexed IFC. Start with the Preparation Setup Summary, then use Schema Builder, Source Mapping, and User-defined Measurement Rules to generate preparation rows. Optionally save or load a preparation configuration draft. Add session-only row reviews (status + note) on generated rows. Review the Unresolved Data Register, Visual Summary, and Quantity Preparation Insights. Rows eligible for Modify handoff have enough target context — they are not necessarily complete. Raw Indexed Quantity Inventory is secondary reference only. Not Ask, not Modify, not BOQ, not cost, not verified QS measurement.

Lifecycle

After an IFC file is indexed, this page reads entity properties at runtime. Current edits to schema include/exclude, source-type mapping intent, and measurement rules are session-only (GET query params) until you save a named preparation configuration draft. A saved draft stores settings only: basis rules, schema includes, and source mapping intent — not generated quantity rows, totals, register counts, visuals, or row reviews. It does not approve, certify, write back, or create BOQ/cost. Row reviews (status + note) are session-only in this slice — not saved into preparation configuration drafts, and they do not change generated quantities or resolve missing mapping/quantity gaps. Ending the browser session or losing the session may clear row reviews. Refresh without parameters restores defaults unless a prep_config draft is loaded. Generate may continue as session GET params after a draft is loaded. Required/core fields are locked. Excluded optional fields are omitted from the generated table and are not counted as unresolved schema gaps. Source Mapping edits classification / package / work-package source type only — no values are created, no property picker. Sending unresolved rows to Castor Modify is disabled here — Modify owns suggest / review / approve / writeback / Git trace / re-index.

How to use it

  • Preparation Setup Summary — counts for the current configuration.
  • Preparation Configuration Drafts — optional save/load of settings only (basis + schema + source intent). Not generated rows, not row reviews, not BOQ, not verified takeoff, not Modify/writeback, not cost. No active/default/approve profile in this slice.
  • Schema Builder — include/exclude optional fields; core fields stay locked.
  • Source Mapping — choose source type for Classification, Package Mapping, and Work Package (intent until saved as a draft): Future Modify handoff (counted unresolved), Manual field (counted unresolved; enter session values in Review row), Not mapped (intentional blank; not counted).
  • User-defined Measurement Rules — choose a basis per model group. Unit Basis is derived from the selected Quantity Basis.
  • Generate Preparation Data Model — rebuilds prep rows, register, visual summary, and insights from selected schema + source intents + rules.
  • Generated Preparation Data Model — totals only when source + basis are selected and available. Mapping cells show intent hints only, or session-only Manual preparation values when a field is configured as Manual field. Use Review row for session review status/note and eligible manual mapping values. Use Export preparation model (session) for a ZIP snapshot of the current generated model, settings, and session annotations — not BOQ, not cost, not writeback. When a frozen 5D snapshot already exists for the project, use Open latest Schema Insight to open the read-only Schema Quantity Insight report (not BOQ, not cost estimate). If no freeze exists yet, the card explains that Schema Insight reads a frozen snapshot — not the live table — and does not create one.
  • Unresolved Data Register — counts only included schema gaps for counting source intents; no fake readiness percentages. Session row reviews do not change these counts. Session manual mapping values may clear mapping gaps for that row only.
  • Preparation Data Model Visual Summary — count charts from generated rows only.
  • Quantity Preparation Insights — deterministic operational notes (not AI).
  • Raw Indexed Quantity Inventory — input evidence only, at the bottom.

Who can do what

BIM coordinators and quantity reviewers use this page for preparation. Schedule link confirm / ignore stays under Links. IFC enrichment stays under Modify when enabled. Model link diagnostics stay under Model.

Caveats

  • No rule = unresolved. No selected basis = no measurement claim.
  • IfcWall and IfcSlab stay Unresolved until the user selects a basis and generates.
  • Current configuration edits are session-only until saved as a preparation configuration draft.
  • Saved drafts store preparation settings only — not generated quantity rows, not row reviews, and not manual mapping values.
  • Session row reviews do not approve, certify, write back, or generate BOQ.
  • Session manual mapping values are available only for included fields configured as Manual field — session-only annotations.
  • Schema-backed node selections (when a project schema is adopted) are session annotations only — they do not create ClassificationAssignment records, are not approved/certified classifications, and do not write back to IFC. Export schema metadata support comes later (C3c).
  • Session row reviews do not resolve missing basis, quantity source, or mapping gaps.
  • Excluded fields are not counted as unresolved schema gaps.
  • Not mapped means intentional blank — not counted as missing.
  • Future Modify handoff / Manual field count as unresolved mapping gaps until a session value is entered.
  • Package Mapping is preparation grouping — this screen does not generate BOQ or cost output.
  • Send unresolved rows to Castor Modify is disabled in this slice.
  • Advanced tools “Export legacy QTO cache” dumps the optional legacy QTO cache only (may include cost/cache fields if present). It does not export the generated preparation data model, schema, source intent, row reviews, or manual mapping values. Prefer Export preparation model (session) on the Generated Preparation Data Model for the current preparation snapshot.
  • Volume / area / length use IFC-reported model units — not SI-normalized.
  • Hub ?tab=quantities on scheduling does not render this page — use the Quantities hub link.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not invoice or procurement. Not payment valuation. Not company actual cost. Not commercial estimating.
