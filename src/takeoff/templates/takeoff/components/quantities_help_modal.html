How Quantities Works

What is it?

Quantities is the IFC Model Quantities workspace for builder-led quantity preparation. Configure columns and quantity basis rules, review a Generated Preparation Table, and use Model Quantity Reference for indexed Qto_* coverage. This is model quantity foundation for future estimating workflows — not BOQ, cost, or verified QS measurement.

Lifecycle

After an IFC file is indexed, this page reads entity properties at runtime. Column and basis profiles are session defaults in this release (not saved). Classification stays Unavailable until classifications are indexed. Controlled IFC enrichment will later open Castor Modify proposals — no IFC writeback happens directly from this screen. Optional advanced cache / export tools remain demoted.

How to use it

  • Review Column Configuration — which fields feed the preparation table.
  • Review Quantity Basis Rules — starter examples only; material is not auto-detected.
  • Quantity Source = IFC/Qto property used. Quantity Basis = measurement method for the model group.
  • Use Generate Preparation Table to jump to the generated rows.
  • Check Missing Data Summary for blank classification / package / work package fields.
  • Use Model Quantity Reference for With/Missing IFC Qto and class/level/type breakdowns.
  • Treat volume, area, and length totals as IFC-reported model units — not normalized SI.

Who can do what

BIM coordinators and quantity reviewers use this page for preparation and model quantity foundation insight. Schedule link confirm / ignore stays under Links. IFC property enrichment stays under Modify when enabled. Model link diagnostics stay under Model.

Caveats

  • Qto_*.id alone does not count as Has IFC Qto.
  • Classification: Unavailable (not scraped from properties).
  • Zone, Package / BOQ Code, and Work Package stay blank until mapped or enriched.
  • Starter basis rules are examples — review before using for enrichment.
  • Prepare Enrichment Proposal is disabled in this release.
  • Volume / area / length totals use IFC-reported model units as stored — not SI-normalized.
  • Hub ?tab=quantities on scheduling does not render this page — use the Quantities hub link.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not invoice or procurement. Not payment valuation. Not company actual cost. Not commercial estimating.
