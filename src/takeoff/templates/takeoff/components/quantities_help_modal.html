How Quantities Works

What is it?

Quantities is the IFC Model Quantities workspace. It summarizes quantity availability and named measures from indexed model Qto_* properties: Quantity Coverage, Missing IFC Qto, and totals by IFC Class, Level / Storey, and Type when available. This is model quantity readiness for future 5D workflows — not BOQ, QS valuation, ERP, invoice, procurement, payment, company actual cost, or commercial 5D.

Lifecycle

After an IFC file is indexed, this page reads entity properties at runtime (summary-first). Classification stays Unavailable until classifications are indexed. Optional advanced cache / export tools are demoted and are not the primary product.

How to use it

  • Use the stats strip for Quantity Coverage and Missing IFC Qto.
  • Select an IFC Class, Level / Storey, or Type row to inspect measures.
  • Filter or sort the visible By IFC Class grid without changing source data.
  • Open Missing IFC Qto → Inspect IFC Elements to review entities without real Qto.
  • Treat Length / Width / Height / Perimeter as model units, not metres.

Who can do what

BIM coordinators and 5D reviewers use this page read-only for model quantity insight. Schedule link confirm / ignore stays under Links. Model structure stays under Model.

Caveats

  • Qto_*.id alone does not count as Has IFC Qto.
  • Classification: Unavailable (not scraped from properties).
  • Totals sum explicit named measures (e.g. NetVolume, NetArea) — not mixed primary picks.
  • Linear totals use model units as stored in the IFC index.
  • Hub ?tab=quantities on scheduling does not render this page — use the Quantities hub link.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not invoice or procurement. Not payment valuation. Not company actual cost. Not commercial 5D.
