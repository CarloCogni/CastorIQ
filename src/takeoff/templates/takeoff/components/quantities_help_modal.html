How Quantities Works

What is it?

Quantities builds a deterministic Quantity Preparation Data Model from indexed IFC. Start with the Preparation Setup Summary, then use Schema Builder, Source Mapping, and User-defined Measurement Rules to generate preparation rows. Review the Unresolved Data Register, Visual Summary, and Quantity Preparation Insights. Rows eligible for Modify handoff have enough target context — they are not necessarily complete. Raw Indexed Quantity Inventory is secondary reference only. Not Ask, not Modify, not BOQ, not cost, not verified QS measurement.

Lifecycle

After an IFC file is indexed, this page reads entity properties at runtime. Schema include/exclude, source-type mapping intent, and measurement rules are session-only (GET query params) and not saved to the project. Refresh without parameters restores defaults. Required/core fields are locked. Excluded optional fields are omitted from the generated table and are not counted as unresolved schema gaps. Source Mapping edits classification / package / work-package source type only — no values are created, no property picker, and no saved profiles. Sending unresolved rows to Castor Modify is disabled here — Modify owns suggest / review / approve / writeback / Git trace / re-index.

How to use it

  • Preparation Setup Summary — counts for the current session rules.
  • Schema Builder — include/exclude optional fields; core fields stay locked.
  • Source Mapping — choose source type for Classification, Package / BOQ Mapping, and Work Package (session-only intent): Future Modify handoff (counted unresolved), Manual field (counted unresolved; no value entry here), Not mapped (intentional blank; not counted).
  • User-defined Measurement Rules — choose a basis per model group. Unit Basis is derived from the selected Quantity Basis.
  • Generate Preparation Data Model — rebuilds prep rows, register, visual summary, and insights from selected schema + source intents + rules.
  • Generated Preparation Data Model — totals only when source + basis are selected and available. Mapping cells show intent hints only.
  • Unresolved Data Register — counts only included schema gaps for counting source intents; no fake readiness percentages.
  • Preparation Data Model Visual Summary — count charts from generated rows only.
  • Quantity Preparation Insights — deterministic operational notes (not AI).
  • Raw Indexed Quantity Inventory — input evidence only, at the bottom.

Who can do what

BIM coordinators and quantity reviewers use this page for preparation. Schedule link confirm / ignore stays under Links. IFC enrichment stays under Modify when enabled. Model link diagnostics stay under Model.

Caveats

  • No rule = unresolved. No selected basis = no measurement claim.
  • IfcWall and IfcSlab stay Unresolved until the user selects a basis and generates.
  • Schema, source-type, and basis rules are session-only and not saved.
  • Excluded fields are not counted as unresolved schema gaps.
  • Not mapped means intentional blank — not counted as missing.
  • Future Modify handoff / Manual field count as unresolved mapping gaps; no values are invented.
  • Package / BOQ Mapping is a schema field name — this screen does not generate BOQ.
  • Send unresolved rows to Castor Modify is disabled in this slice.
  • Volume / area / length use IFC-reported model units — not SI-normalized.
  • Hub ?tab=quantities on scheduling does not render this page — use the Quantities hub link.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not invoice or procurement. Not payment valuation. Not company actual cost. Not commercial estimating.
