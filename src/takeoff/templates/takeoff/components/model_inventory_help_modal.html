How Model Inventory Works

What is it?

Model Inventory is a summary of the project’s IFC index: how many elements exist, by IFC class, how many have trusted schedule-model links, and how many expose IFC model quantities (Qto_*). It supports 4D apply/read readiness and future 5D foundation work.

How to use it

  • Scan Overview for total entities, classes, storeys, and coverage.
  • Use By IFC Class to find large unlinked groups before Apply / 4D Link.
  • Open Viewer or Apply / 4D Link from the action links when you need to act.

Who can do what

BIM coordinators, planners, and 4D/5D reviewers use this page read-only. Approving or rejecting links is done in Apply / 4D Link and Link Quality — not here.

Caveats

  • Link coverage uses trusted schedule-model links only.
  • Quantity availability depends on IFC Qto_* data in the indexed model.
  • Counts come from the IFC index — not live geometry re-measure.
