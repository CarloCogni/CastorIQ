How Model Works

What is it?

Model is the project’s IFC Model Inventory workspace: KPI overview, By IFC Class and By Level / Storey grids, Missing Model Data, Link Coverage, and an IFC Elements grid. Link coverage uses applied / confirmed schedule-model links only. Quantity readiness uses IFC model quantities (Qto_*), not BOQ.

Lifecycle

After an IFC file is indexed, this page reads the completed IFC index. Confirm Link / Ignore Suggestion still happens under Links — not here. Classification Coverage stays Unavailable until classifications are indexed.

How to use it

  • Scan KPI cards and Link Coverage first.
  • Use the By IFC Class and By Level / Storey grids for inventory breakdowns.
  • Open IFC Elements for the full filterable grid.
  • Open Viewer or Open Links for navigation only — this page does not focus the viewer.

Who can do what

BIM coordinators, planners, and 4D/5D reviewers use this page read-only. Suggest Links / Confirm Link / Ignore Suggestion happens under Links → Applied Links.

Caveats

  • Link coverage uses applied / confirmed schedule-model links only.
  • Has IFC Qto depends on IFC Qto_* data in the indexed model.
  • Classification Coverage: Unavailable (not scraped from properties).
  • IFC Elements is a paginated inspection list, not a full model browser.
  • Counts come from the IFC index — not live geometry re-measure.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not company actual cost. Not commercial 5D / cost control. Not a Synchro replacement.
