How Model Works

What is it?

Model is the 4D/5D Model Readiness dashboard: overall status, filters, visual charts (element links, task links, floor/zone sequencing, QTO, granularity, playback), then next actions, then inventory evidence tables. Element link coverage uses applied / confirmed schedule-model links only. QTO readiness uses IFC model quantities (Qto_*), not BOQ. This page does not replace Explore, Viewer, Quantities, or Time View playback.

Lifecycle

After an IFC file is indexed, this page reads the IFC index and existing links. Parameter Match still happens under Links. Playback lives under Time View. Classification not indexed until classifications exist. Task Legend Groups need a later saved appearance profile — not an active feature.

How to use it

  • Read overall status and the four headline metrics first.
  • Use filters to focus class/level and the element list. Task, playback, and granularity charts stay project-wide.
  • Follow a next action: Open Links, Open Quantities, or Open Time View.
  • Scroll to Inventory evidence to inspect the class, level, and element tables.
  • Viewer is a secondary shortcut — this page does not embed the viewer.

Who can do what

BIM coordinators, planners, and 4D/5D reviewers use this page read-only. Rule-based linking happens under Links. Programme playback happens under Time View.

Caveats

  • Element link coverage and task link coverage use different denominators.
  • Has IFC Qto depends on IFC Qto_* data in the indexed model.
  • Classification not indexed (not scraped from properties).
  • Playback chart does not run Time View and does not colour the model here.
  • IFC Elements is a paginated inspection list, not Explore.

Not claimed

Not BOQ. Not QS valuation. Not ERP. Not company actual cost. Not commercial 5D / cost control. Not a Synchro replacement. Not Explore. Not Viewer. Not Time View playback. Not Task Legend Groups. Not an IFC-class custom 4D legend.
