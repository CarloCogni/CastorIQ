How Schema Quantity Insight Works

What is it?

This page summarizes IFC-derived quantities using the project schema saved in the selected snapshot. It is intended for review of grouping, mappings, gaps, and provenance. Cost calculation, approvals, and schedule cost loading are separate workflows.

Lifecycle

Prepare quantities and mappings → freeze a 5D snapshot → open this report. The report reads the frozen snapshot and does not change it.

How to use it

  • Check snapshot summary for the version you are reviewing.
  • Review classification and package rollups.
  • Check work package rollup — it may still be mostly Unmapped.
  • Use gaps and the issue sample to see what still needs mapping or basis setup.
  • Return to Quantities to adjust mappings, then freeze a new snapshot.

Who can do what

Project members with access can open the report. Mapping happens in Quantities. Snapshot creation is a separate action. This page is read-only.

Caveats

  • Session schema mapping is preparation provenance, not an approved assignment.
  • Mixed quantity bases and units are shown separately, not merged.
  • External Excel or Ask import into this schema is not connected yet.
