How 5D Quantity Review Works

What is it?

This page summarizes IFC-derived quantities using the project schema saved in the selected snapshot. Start with coverage, then review mapped groups and the work queue. Cost calculation, approvals, and schedule cost loading are separate workflows.

How to use it

  • Read Schema insight summary and the coverage bar first.
  • Use Classification / Package / Work Package tabs one at a time.
  • Check What needs attention for the next setup steps.
  • Open Advanced details only for technical traceability.
  • Return to Quantities to adjust mappings, then freeze a new snapshot.

Caveats

  • Session schema mapping is preparation provenance, not an approved assignment.
  • Units stay unresolved until model/snapshot units are confirmed via the Quantities Quantity units panel (session confirmation, then freeze).
  • Total Quantity, Unit, and Measurement Basis are separate review fields — never merged into one label.
  • External Excel or Ask import into this schema is not connected yet.
