How Castor Viewer Works

What is Castor Viewer?

Castor Viewer is the 3D model inspection surface. Colour elements by material, level, type, or schedule-status coverage. Programme playback of applied / confirmed links lives in Time View. This viewer is not a construction simulation or walkthrough.

Color By Filters

None — restore default ifc-lite colours. Material / Level / Element Type — each unique group gets a distinct colour from a 12-colour palette. The legend appears in the viewer overlay. Schedule Status — green = entity has an Activity ID property linked to a schedule task; grey = not linked. Instant visual gap map.

Gap Analysis Panel

Opens a side panel grouped by Level, Element Type, or Material. Each row shows how many elements are linked to a schedule task versus total. Click any row to highlight the unlinked elements in the 3D view. Export the full table as CSV.

"Linked" here means the entity has an Activity ID property used for coverage counts. Applied / confirmed schedule-model links are created in the Links tab.

Programme playback

Weekly model colouring by schedule state is owned by Time View (look-ahead window + programme playback). This standalone viewer does not show a timeline scrubber.

Scale Figure

Scale Figure adds a simple non-human height reference to help judge model scale. It is not a worker, avatar, safety simulation, walkthrough recording, or navigation log. Height is approximate and based on model units. Use Show Scale Figure / Reset Scale Figure on the view toolbar.

Caveats

Color By applies colours to the model — click Reset to restore defaults. Gap Analysis counts Activity ID coverage only — other schedule linkage methods are not reflected. Scale Figure height is ~1.75 model units; IFC unit metadata is not read — size may look wrong if the model is not metre-scaled.
