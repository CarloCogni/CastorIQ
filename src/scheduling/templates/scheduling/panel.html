How TimeLiner works

What is it? Visual schedule–model review: link construction tasks to IFC elements for 4D navigation. Not a full simulation replacement.

Workflow:

  1. Schedule — Gantt-first workspace for the imported programme (activities, dates, progress, calendars, Schedule Readiness). Use Table / Columns for mapping review; Import / Replace Schedule when updating the file. Select a task for details and jump to Links or Time View.
  2. Links — rule-based Parameter Match / Link Check, then apply matches with an explicit action. Manual fallback is secondary. Model colours in Time View use applied / confirmed links only.
  3. Schedule Readiness (internal) — DCMA and supporting schedule checks. Assignment-basis indicators live under Controls → Schedule / Assignment Indicators.
  4. Time View — programme playback of linked model colours over programme dates. Unlinked activities do not colour the model. Walkthrough is not available.
  5. Intelligence (diagnostic, not in nav) — advisory Q&A over schedule text. Answers are suggestions only; they do not approve links or change the programme. Verify against your schedule before acting.

Caveats: Link Check is preview-only until Apply Preview Matches. Elements must be processed for best coverage. Missing actual cost is unavailable, not fabricated. Always verify LLM output against your programme.
