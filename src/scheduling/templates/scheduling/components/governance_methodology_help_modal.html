Governance Methodology

Trust states

Trusted = is_active, governance_status=trusted, needs_review=false. Active review = active + active_review + needs_review=true. Rejected, reversed, and superseded bindings are inactive and excluded from trusted and review reads.

Coverage denominators

Task coverage numerator = distinct tasks with trusted bindings. Denominator = all schedule activities (includes procurement, milestones, non-model work). Entity coverage numerator = trusted entity GIDs; denominator = indexed entities in completed IFC files. Low task % with high entity % can both be valid on the same project.

Evidence and confidence

Evidence labels (exact, normalized, manual, heuristic, semantic) describe the match channel — not approval authority. Confidence never auto-trusts. Property Activity ID metadata is not a binding. Legacy M2M without a trusted binding is compatibility storage only.

Lifecycle and audit

Approve, reject, reaffirm, reverse, supersede, and parity repair create append-only events prospectively after migration 0024. Pre-audit trusted rows (e.g. IBS baseline) have no historical events. Zero events does not mean zero historical decisions.

Reconciliation

Reconciliation is diagnostic only — run explicitly; results are not cached on overview load. Drift checks compare indexed IFC snapshots; version lineage has known limits.
