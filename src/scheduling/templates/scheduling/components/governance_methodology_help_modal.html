Link Coverage Methodology

Applied / Confirmed vs review

Applied / Confirmed links are active, confirmed, and not awaiting review. Review items are suggestions that still need Confirm Link or Ignore Suggestion. Inactive ignored / reversed / superseded links are excluded from Time View and Controls reads.

Coverage denominators

Task coverage numerator = distinct tasks with applied / confirmed links. Denominator = all schedule activities (includes non-model work). Entity coverage numerator = applied entity GlobalIds; denominator = indexed IFC entities.

Evidence and confidence

Evidence labels describe the match channel — not confirmation status. Confidence never auto-confirms. Property Activity ID metadata alone is not a binding.

Lifecycle and audit

Confirm Link, Ignore Suggestion, reaffirm, reverse, supersede, and parity repair create append-only events. Pre-audit rows may have no historical events.

Reconciliation

Reconciliation is diagnostic only — run explicitly; results are not cached on overview load.
