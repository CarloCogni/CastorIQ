How Executive Controls Work

Performance matrix hierarchy

When canonical WBS is populated, the matrix groups by selected WBSVersion nodes — not Task stage. Stage analysis remains available only via the explicitly labelled Stage Proxy view. Partial canonical coverage shows unassigned tasks in a separate bucket.

Analytical state

Metrics reflect Live Current Analytical State — they update when schedule or model data is re-imported. No frozen snapshot is selected.

Baseline / reference limitation

Baseline dates come from Current Reference/Baseline Fields from Imported Schedule — not a contractual baseline until BaselineVersion exists.

Planned / actual progress

Progress weighting follows the active performance mode (cost-weighted BAC or duration proxy). Each card shows numerator, denominator, and methodology badge.

Cost EVM vs Schedule Performance

Cost EVM requires defensible cost and actual cost data. Duration-weighted schedule performance is labelled separately and is not monetary Earned Value.

Delay types

Primary delay states (completed late, currently late, forecast late, not late) are mutually exclusive. Risk indicators (critical, negative float, etc.) may overlap.

Trusted model scope

Model impact uses accepted active bindings only. Task coverage (all activities) and entity coverage (indexed IFC entities) use separate denominators.

Caveats

Re-import may change KPIs silently until snapshot support lands. Keyword scope suggestions are not authoritative. Equivalent workforce curves are defined but not shown until E8-E.
