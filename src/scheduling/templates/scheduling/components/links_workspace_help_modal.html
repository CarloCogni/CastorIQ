How Links Works

What is it?

Links is a parameter / rule-based schedule–model linking workspace. You configure a Link Rule (schedule field ↔ model parameter), run a read-only Link Check, review Match Results, then apply matches only with an explicit action. Model Context stays central for visual confirmation.

Lifecycle

  1. Open Rules and pick a preset (Activity Code ↔ Activity ID) or a custom parameter.
  2. Click toolbar Run Link Check — dry-run / preview only; no links are written.
  3. Review Match Results — Matched, Unmatched Activities, Unmatched Model Elements, Conflicts.
  4. Use Highlight Mode to select several activities and highlight their applied model links together.
  5. Use Apply Preview Matches in the Results drawer only when you intend to persist the latest preview set.
  6. Select an activity and use Manual fallback only for individual exceptions.

How to run a Link Check

  • Run Link Check stays on the toolbar and is always visible.
  • Enter the IFC / Revit property that holds the activity code (e.g. Activity ID) in the Rules drawer.
  • Match type is exact equality for this version.
  • Match Results opens as an overlay drawer after Link Check — Model Context stays full height behind it.
  • The left panel is an activity list (not a Gantt timeline). Schedule owns the timeline.
  • Collapse the inspector to give Model Context more width. It stays collapsed until you reopen it from the slim rail or Inspector toggle. Selecting an activity does not reopen it.
  • Highlight Mode shows checkboxes on activity rows. Choose a Highlight color, then Highlight Selected to paint those activities. Later checks can use a different color; re-highlighting reassigns color. This is read-only and does not write links. Selecting an activity outside Highlight Mode does not change the model.
  • Focus Highlighted zooms the camera. Isolate Highlighted dims the rest of the model. They are different actions.
  • Select a model element in Model Context to enable Link Selected Element.
  • Model Context camera controls: Zoom In, Zoom Out, Reset View (camera only — does not clear highlights), and Focus when an element is selected. Link Check colors applied vs unlinked elements. There is no Site control.

Who can do what

Any member with schedule access can run Link Check (read-only). Apply Links and Manual fallback require modify / link permission on the project.

Caveats

Matching is rule-based and deterministic only. Contains / fuzzy matching, WBS, Level + Type, and applying a selected subset of preview rows are not available yet. Link Check never creates bindings by itself. Apply Preview Matches writes the latest preview set. Schedule writeback is not available here.
