How Time View Works

What is it?

Time View is programme playback for the linked model timeline. Scrub or play programme dates to colour the 3D model by schedule state. Model colours use applied / confirmed links only. This is not a walkthrough or construction simulation.

Programme playback

  • The bottom dock holds Start / Previous / Play / Pause / Next and the scrubber.
  • Playback Setup sets presentation duration (30 sec / 1 min / 3 min / 5 min). Step delay is duration ÷ weekly intervals.
  • Programme range and weekly step are read-only in this release.
  • Playback defaults near today’s as-of date when timeline intervals exist.
  • Details (closed by default) show interval linked-element counts for the current playback date.

Appearance

  • Active appearance profile: Schedule state (complete / in progress / delayed / not started).
  • The on-model legend is generated from that profile and visibility toggles.
  • An applied-count chip reports how many linked elements were coloured for the playback date.
  • Task Legend Groups (user-defined activity tags with colours) are planned — not IFC class categories. Not available in this release.

Model colours

  • Uses the latest processed IFC for this project.
  • Only applied / confirmed schedule-model links colour the model.
  • Unlinked schedule activities do not appear in model colours.
  • Create or check links in the Links tab. Walkthrough / camera-path playback is not available in this release.

Who can do what

Any project member with schedule access can view Time View and programme playback. Creating or editing task-to-model links requires modify access on Links.

Caveats

This is a read-only playback view — no links are created here. Colouring depends on schedule dates, applied / confirmed links, and a processed IFC file. Missing links are not inferred. Interval step is weekly in this release.
