How Link Governance Work
What is it?

Read-only workspace separating trusted accepted bindings, review suggestions, property hints, legacy M2M compatibility, and deterministic possible conflicts under policy trusted-binding-v1.

Trusted vs review

Trusted means needs_review=False. Review suggestions never drive colormap, readiness, or viewer highlights. Property Activity ID metadata is evidence only.

How to use this page

Switch queue modes, filter by method or confidence, open evidence panels, and navigate to task detail or the model viewer. Approve/reject controls arrive in E2-C.

Caveats

Multiple accepted tasks on one entity are allowed unless overlap evidence triggers a possible conflict. Legacy M2M rows without accepted bindings are compatibility storage only.
