How Resource / Cost Data Readiness works

What this page shows

Assignment data readiness for Executive Controls: coverage, manhour units from recorded schedule resource assignments, and source/provenance labels. It is not resource planning, headcount, leveling, payroll, attendance, or company/ERP spend.

Lifecycle / source

Totals prefer canonical ResourceAssignment. P6 is used only if this project has no canonical assignments yet. Legacy pilots may lack source_version; that gap is labelled, not hidden.

How to read

Manhours are assignment units, not attendance. Equivalent workforce (if shown in advanced) estimates effort from manhours divided by working-day assumptions — never site headcount. Unavailable means required data is missing or not meaningful — it is never treated as zero.

Who uses it

Project controls checking whether schedule assignment cost/unit data is ready for assignment-basis EVM indicators — before trusting deeper analytics.

Caveats

Not site headcount Not resource leveling Not full resource planning Not full cost management Assignment units are not attendance records Workforce curves and time-phased histograms remain deferred
