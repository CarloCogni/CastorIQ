How Resources Readiness works

What this page shows

Resource readiness for Executive Controls: assignment coverage, manhour KPIs from recorded resource assignments, and source/provenance labels. It is not a full E8-E resource planning dashboard.

Lifecycle / source

Totals prefer canonical ResourceAssignment. P6 is used only if this project has no canonical assignments yet. Legacy pilots may lack source_version; that gap is labelled, not hidden.

How to read

Manhours are assignment units, not attendance. Equivalent workforce estimates effort from manhours divided by working-day assumptions. Unavailable means required data is missing or not meaningful — it is never treated as zero.

Who uses it

Project controls and planners checking whether resource cost/unit data is ready for EVM, cashflow, and workforce summaries — before trusting deeper resource analytics.

Caveats

Not site headcount Not resource leveling Not full resource planning Not full cost management Assignment units are not attendance records Workforce curves and time-phased histograms remain deferred
