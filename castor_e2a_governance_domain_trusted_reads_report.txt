4. Trust Policy
================================================================================
Policy ID: trusted-binding-v1
Module: scheduling/services/governance/policy.py

Rules:
  - Accepted/trusted = TaskEntityBinding.needs_review=False
  - Review = needs_review=True (never trusted)
  - Property metadata (Activity ID) = evidence hint only
  - Task.ifc_entities M2M = compatibility storage only
  - Normalized/heuristic/embedding = review-only suggestions
  - Multiple accepted tasks allowed; conflict requires explicit overlap evidence

5. Binding Governance Reader
================================================================================
Module: scheduling/services/governance/reader.py

BindingGovernanceReader(project_id):
  - trusted_bindings_qs / review_bindings_qs (project-scoped via task__project)
  - trusted_entity_gids(ifc_scope=) — optional IFC file scope filter
  - trusted/review entity and task lookups (task-scoped, entity-scoped)
  - entity_gids_by_task(trusted_only/review_only)
  - trusted_counts, method_distribution
  - entities_with_multiple_trusted_tasks
  - legacy_m2m_only_relation_count (SQL anti-join at scale)
  - property_hint_entity_count (excludes trusted gids; short-circuit when full coverage)

link_resolver.py delegates trusted project reads to reader.
